# 算法定价与默契合谋复现

本仓库记录对 Calvano et al. (2020)
《Artificial Intelligence, Algorithmic Pricing, and Collusion》
的五步独立复现。

## 内容

1. 第一步：搭建经济环境。
2. 第二步：搭建最小 Q-learning 实验。
3. 第三步：复现基准结果，重点对应表1。
4. 第四步：检验“偏离—惩罚—恢复”机制。
5. 第五步：进行最佳回应检验，区分稳定与均衡。

## 使用方法

下载 HTML 文件后，用浏览器打开，
即可查看说明、代码、交互图表及下载入口。
第五步以 ZIP 保存，使用前先解压。

## 复现说明

本项目属于独立实现，部分结果与原论文存在差异。
尤其是完整动态最佳回应检验，尚未匹配原论文的均衡比例。
具体定义、计算方法、验证结果及差异说明见各步骤报告。
