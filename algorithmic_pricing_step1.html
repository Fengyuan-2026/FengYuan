02 / 完整价格组合与利润表

每一行是一组同时选择的价格。q₀ 是不购买的份额；两家销量与外部选项份额之和为1。π₁、π₂ 是各自单期利润。

ijp₁p₂q₁q₂q₀π₁π₂

i、j 是从1开始的价格档位。后续训练可直接把利润表转成 π₁[i,j]、π₂[i,j] 数组；Python 内部列表索引从0开始。

03 / 模型、推导与实现边界

① 市场需求和利润

D = exp((a−p₁)/μ) + exp((a−p₂)/μ) + exp(a₀/μ)
qᵢ = exp((a−pᵢ)/μ) / D，q₀ = exp(a₀/μ) / D
πᵢ = (pᵢ−c)qᵢ

市场规模标准化为1；质量、成本和外部选项为外生参数。实现使用减去最大指数的 softmax 写法，以减少直接计算指数产生的数值溢出。

② 连续价格下的静态纳什均衡

求企业 i 的最优回应时，保持对手价格不变。由 ∂qᵢ/∂pᵢ = −qᵢ(1−qᵢ)/μ，可得：

∂πᵢ/∂pᵢ = qᵢ[1 − (pᵢ−c)(1−qᵢ)/μ] = 0
对称解：pᴺ = c + μ/(1−qᵢ(pᴺ,pᴺ))

不能先把双方价格绑定成同一个变量，再对“某一家利润”求导来寻找纳什均衡；那样会把对手价格也一起改变。

③ 联合利润最大化

两家企业共同最大化 Π = π₁ + π₂。对称成本和质量下，联合最优具有相同加价。利用 q₀ = 1−q₁−q₂，有：

pᴹ = c + μ/q₀(pᴹ,pᴹ)
求根形式：1 − (p−c)q₀(p,p)/μ = 0

“垄断基准”指控制两个产品价格的联合利润最大化者，需求分母仍然包含两个产品；并非删掉一家企业后重算单产品市场。

④ 价格离散化

L = pᴺ − ξ(pᴹ−pᴺ)，U = pᴹ + ξ(pᴹ−pᴺ)
A = { L + j(U−L)/(m−1) : j = 0,…,m−1 }

正文 II.B 给出网格规则；本页面按 II.E 使用 ξ=0.1、m=15。价格均衡用二分法求根，价格区间精度设为10⁻¹²。Python 与浏览器分别实现同一模型。

适用范围：对称双寡头、常数成本、μ>0。本实现不处理非对称企业、μ=0的完全替代极限、动态进入退出和算法学习。页面参数范围是本工具的操作边界，不是论文对参数的理论限制。

#!/usr/bin/env python3
"""Calvano et al. (AER, 2020): symmetric two-firm economic environment.
Independent implementation from Section II.A/B/E, not the authors' code.
Python 3.9+; standard library only. No Q-learning or collusion simulation.
Run: python economic_environment.py
Custom: python economic_environment.py --config parameters.json --out results
Price indices in CSV are 1-based. Internally Python lists are 0-based.
"""
import argparse
import csv
import json
import math
from pathlib import Path

BASELINE = dict(a=2.0, c=1.0, a0=0.0, mu=0.25, xi=0.1, m=15)
BOUNDS = dict(a=(0, 10), c=(0, 10), a0=(-5, 5), mu=(0.05, 2),
              xi=(0.01, 1), m=(3, 51))

def validate(params):
    if set(params) != set(BASELINE):
        raise ValueError('Parameters must be exactly a, c, a0, mu, xi, m')
    for key, (lo, hi) in BOUNDS.items():
        v = params[key]
        if isinstance(v, bool) or not isinstance(v, (float, int)) or not math.isfinite(v):
            raise ValueError(f'{key} must be finite and numeric')
        if not lo <= v <= hi:
            raise ValueError(f'{key} must lie in [{lo}, {hi}]')
    if int(params['m']) != params['m']:
        raise ValueError('m must be an integer')

def market(p1, p2, params):
    """Stable logit shares [q1,q2,q0] and single-period profits."""
    a, c, a0, mu = (params[k] for k in ('a', 'c', 'a0', 'mu'))
    z = [(a-p1)/mu, (a-p2)/mu, a0/mu]
    top = max(z)
    weights = [math.exp(v-top) for v in z]
    total = sum(weights)
    q1, q2, q0 = [v/total for v in weights]
    return dict(q1=q1, q2=q2, q0=q0,
                pi1=(p1-c)*q1, pi2=(p2-c)*q2)

def bisect_above_cost(func, params):
    """Positive FOC at marginal cost; find negative upper bound, then bisect."""
    lo = params['c']
    width = max(1.0, params['mu'])
    hi = lo + width
    for _ in range(100):
        if func(hi) < 0:
            break
        width *= 2
        hi = lo + width
    else:
        raise RuntimeError('Unable to bracket price root')
    for _ in range(200):
        mid = (lo+hi)/2
        if hi-lo < 1e-12:
            break
        if func(mid) > 0:
            lo = mid
        else:
            hi = mid
    return (lo+hi)/2

def solve_benchmarks(params):
    """Continuous-price symmetric Nash and joint-profit maximizer.
    Nash: 1-(p-c)(1-q_i)/mu = 0 (own-price FOC, rival held fixed).
    Monopoly: 1-(p-c)q_0/mu = 0 (common markup, joint objective).
    """
    c, mu = params['c'], params['mu']
    fn = lambda p: 1-(p-c)*(1-market(p,p,params)['q1'])/mu
    fm = lambda p: 1-(p-c)*market(p,p,params)['q0']/mu
    pn = bisect_above_cost(fn, params)
    pm = bisect_above_cost(fm, params)
    return {'nash': dict(price=pn, **market(pn,pn,params)),
            'monopoly': dict(price=pm, **market(pm,pm,params))}

def build_environment(params=None):
    params = dict(BASELINE if params is None else params)
    validate(params)
    b = solve_benchmarks(params)
    pn, pm = b['nash']['price'], b['monopoly']['price']
    low = pn-params['xi']*(pm-pn)
    high = pm+params['xi']*(pm-pn)
    m = int(params['m'])
    grid = [low+j*(high-low)/(m-1) for j in range(m)]
    rows = [dict(i=i+1, j=j+1, p1=p1, p2=p2, **market(p1,p2,params))
            for i,p1 in enumerate(grid) for j,p2 in enumerate(grid)]
    symmetry_error = max(abs(r['pi1']-rows[(r['j']-1)*m+r['i']-1]['pi2'])
                         for r in rows)
    probability_error = max(abs(r['q1']+r['q2']+r['q0']-1) for r in rows)
    # Analytic FOC residuals, with independent finite-difference checks.
    nash_foc = abs(1-(pn-params['c'])*(1-b['nash']['q1'])/params['mu'])
    monopoly_foc = abs(1-(pm-params['c'])*b['monopoly']['q0']/params['mu'])
    h = 1e-5
    derivative_n = (market(pn+h,pn,params)['pi1']-market(pn-h,pn,params)['pi1'])/(2*h)
    def joint(p1,p2):
        r = market(p1,p2,params)
        return r['pi1']+r['pi2']
    derivative_m = (joint(pm+h,pm)-joint(pm-h,pm))/(2*h)
    lower = market(pn-h,pn,params)
    upper = market(pn+h,pn,params)
    check_values = dict(probability_sum_error=probability_error,
                        symmetry_error=symmetry_error,
                        nash_foc_residual=nash_foc,
                        monopoly_foc_residual=monopoly_foc,
                        nash_finite_difference=derivative_n,
                        monopoly_finite_difference=derivative_m)
    checks = dict(
        shares_sum_to_one=probability_error < 1e-12,
        swapped_firms_symmetric=symmetry_error < 1e-12,
        nash_foc=nash_foc < 1e-8,
        monopoly_foc=monopoly_foc < 1e-8,
        finite_difference_nash=abs(derivative_n) < 1e-6,
        finite_difference_monopoly=abs(derivative_m) < 1e-6,
        own_demand_decreases=upper['q1'] < lower['q1'],
        rival_demand_increases=upper['q2'] > lower['q2'],
        all_values_finite=all(math.isfinite(v) for r in rows for v in r.values()),
        benchmark_order=params['c'] < pn < pm,
        grid_covers_benchmarks=grid[0] < pn < pm < grid[-1])
    if not all(checks.values()):
        raise AssertionError({'checks': checks, 'values': check_values})
    # Enumerate pure Nash equilibria of the discretized one-shot game separately.
    # This is not the continuous Nash benchmark and is not a repeated-game result.
    best1 = [max(rows[i*m+j]['pi1'] for i in range(m)) for j in range(m)]
    best2 = [max(rows[i*m+j]['pi2'] for j in range(m)) for i in range(m)]
    pure = [r for r in rows if r['pi1'] >= best1[r['j']-1]-1e-12
            and r['pi2'] >= best2[r['i']-1]-1e-12]
    grid_joint = max(rows, key=lambda r:r['pi1']+r['pi2'])
    return dict(parameters=params, benchmarks=b, price_grid=grid,
                grid_step=(high-low)/(m-1), payoffs=rows,
                discrete_pure_nash=pure, grid_joint_maximum=grid_joint,
                checks=checks, check_values=check_values,
                metadata=dict(source='Calvano et al. 2020, AER 110(10):3267-3297, Section II.A/B/E',
                              implementation='Independent; no learning; symmetric duopoly',
                              index_base=1, solver='Bisection; absolute price tolerance 1e-12'))

def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--config', type=Path, help='JSON with all six parameters')
    parser.add_argument('--out', type=Path, default=Path('economic_environment_results'))
    args = parser.parse_args()
    params = json.loads(args.config.read_text(encoding='utf-8-sig')) if args.config else BASELINE
    result = build_environment(params)
    args.out.mkdir(parents=True, exist_ok=True)
    (args.out/'environment.json').write_text(json.dumps(result,ensure_ascii=False,indent=2),encoding='utf-8')
    with (args.out/'payoff_table.csv').open('w', newline='', encoding='utf-8-sig') as f:
        w = csv.DictWriter(f, fieldnames=list(result['payoffs'][0]))
        w.writeheader(); w.writerows(result['payoffs'])
    with (args.out/'price_grid.csv').open('w', newline='', encoding='utf-8-sig') as f:
        w = csv.writer(f); w.writerow(['index','price'])
        w.writerows(enumerate(result['price_grid'], start=1))
    print(json.dumps({'benchmarks':result['benchmarks'], 'checks':result['checks'],
                      'rows':len(result['payoffs']), 'output':str(args.out.resolve())}, indent=2))

if __name__ == '__main__':
    main()
